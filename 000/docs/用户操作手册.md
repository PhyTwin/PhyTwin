# 用户操作手册

## 1. 安装

在项目目录创建虚拟环境并安装：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[plot]"
```

## 2. 第一次运行

```powershell
omt-sim run examples\quick_demo.json
```

程序每到输出时刻显示时间、步数、动能、磁扰动能和估计 Nusselt 数。看到“计算完成”即表示末态文件写入成功。

## 3. 生成自己的配置

```powershell
omt-sim init-config my_case.json
```

用文本编辑器修改 `my_case.json`。常用参数：

| 参数 | 作用 | 调整建议 |
|---|---|---|
| `modes_x/modes_y` | 两方向截断模态数 | 场结构复杂时提高 |
| `oversampling` | 非线性积分网格加密倍数 | 推荐 1.5–2.0 |
| `buoyancy` | 温度对涡量的驱动 | 提高后对流通常增强 |
| `lorentz` | 磁场对流动的反馈 | 与背景磁场配合分析 |
| `imposed_vertical_magnetic_field` | 背景竖直磁场 | 设 0 可研究无外磁场问题 |
| `background_temperature_gradient` | 基础温度梯度 | 设 0 可关闭背景热对流驱动 |
| `heat_source_amplitude` | 局部热源幅值 | 设 0 关闭热源 |
| `tail_energy_target` | 高模态控制触发目标 | 越小过滤越积极 |
| `filter_strategy` | `synchronized`、`independent` 或 `off` | 默认使用同步策略；后两者用于消融对比 |

## 4. 读取结果

查看 NPZ 内容摘要：

```powershell
omt-sim inspect results\quick_demo\final_state.npz
```

在 Python 中读取：

```python
import numpy as np

data = np.load("results/quick_demo/final_state.npz")
x = data["x"]
y = data["y"]
temperature = data["temperature"]
u = data["u"]
v = data["v"]
```

数组物理场形状为 `(nx, ny)`。绘图时通常使用 `temperature.T` 与 `(x,y)` 对应。

## 5. 结果判读

- `vorticity_tail_ratio` 等持续接近或超过目标：当前模态可能不足；
- `filter_strength` 频繁达到最大值：优先增加模态数，再检查参数是否过强；
- 时间步频繁回退：减小 `max_dt`、降低 `cfl` 或提高分辨率；
- `nusselt_estimate` 是本模型归一化下的估计值，不应在未统一无量纲定义时直接与实验数值比较；
- 两个散度诊断为结构性零值，来源于势函数表示，并非有限差分估算。

## 6. 常见错误

`ModuleNotFoundError: orthomagtherm`：尚未执行可编辑安装，或没有用 `run_demo.py`。

没有生成 PNG：安装 `matplotlib` 后重跑；NPZ 和 CSV 不受影响。

“时间推进连续回退失败”：先把 `max_dt` 减半；若尾能很高，再增加模态数。

## 7. 二次开发入口

- 增加物理项：修改 `solver.py` 的 `nonlinear_terms`；
- 增加边界类型：需要新增基函数类，不应直接破坏正弦基的边界解释；
- 增加诊断量：修改 `diagnostics.py`；
- 增加输出格式：扩展 `io.py`，保持 `ModalState` 不依赖具体文件格式。
