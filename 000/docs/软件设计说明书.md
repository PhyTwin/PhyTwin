# 正交模态热磁流体多物理场数值计算软件 V1.0

## 1. 软件概述

本软件用于矩形区域内二维不可压缩流体、感应磁场与温度场的耦合数值模拟。主要面向计算流体力学教学、热磁对流机理分析、算法验证和二次开发。

软件采用 Python 3 开发，数值核心仅依赖 NumPy。输入为 JSON 配置，输出为 CSV 诊断数据、NPZ 模态/物理场数据和可选 PNG 图像，便于复现实验与追踪参数。

## 3. 数学模型

### 3.1 势函数表示

对二维速度场引入流函数 `ψ`，对二维磁场引入面外磁势 `a`：

```text
u = ψ_y,     v = -ψ_x,     ω = -Δψ
Bx = a_y,    By = B0-a_x,  j = -Δa
```

任意足够光滑的 `ψ` 和 `a` 均给出 `∇·u=0`、`∇·B=0`。这使两种散度约束不依赖额外压力修正或清洁方程。

### 3.2 耦合方程

```text
ω_t = J(ψ,ω) + νΔω + Cb θ_x + Cm[J(j,a)+B0 j_y]
a_t = J(ψ,a) + B0 ψ_y + ηΔa
θ_t = J(ψ,θ) - G ψ_x + κΔθ + Q(x,y)
```

符号含义：

- `ν`：运动黏性系数；
- `η`：磁扩散系数；
- `κ`：热扩散系数；
- `Cb`：浮力耦合系数；
- `Cm`：洛伦兹力耦合系数；
- `B0`：外加竖直背景磁场；
- `G`：背景温度向下梯度；
- `Q`：可选局部热源；
- `J(f,g)=f_x g_y-f_y g_x`。

本模型属于二维电阻磁流体/Boussinesq 型简化模型，不包含可压缩性、三维磁场拉伸、霍尔项、辐射换热和相变。

## 4. 正交 Galerkin 离散

在 `Ω=(0,Lx)×(0,Ly)` 上采用连续归一化基

```text
φmn(x,y)=sqrt(2/Lx)sin(mπx/Lx) · sqrt(2/Ly)sin(nπy/Ly)
```

场变量展开为 `q_MN=Σ q_mn φ_mn`。拉普拉斯算子在该基下对角化：

```text
-Δφmn = [(mπ/Lx)^2+(nπ/Ly)^2] φmn
```

非线性 Jacobian 先在高于模态数的内点求积网格上重构并相乘，再计算内积投影。这比在原始模态数同尺寸网格上直接相乘更能抑制二次卷积混叠，同时保留 Galerkin 残量对试验空间的正交关系。

## 5. 时间推进

首步采用显式非线性与隐式扩散的 IMEX Euler。后续采用可变步长二阶 Adams–Bashforth/Crank–Nicolson：扩散项隐式对角求解，耦合项显式外推。由于拉普拉斯在正交基上对角化，每个模态只需求解一个标量分式，不构造大型稀疏矩阵。

CFL 控制同时考虑流速和按洛伦兹系数缩放的磁传播速度。候选步出现非有限数或模态总范数异常增长时，软件将时间步减半并重算；只有通过检查的候选状态才提交。

## 6. 跨场同步模态尾能控制

软件分别计算三类能量意义下的高阶模态占比：

- 涡量系数以 `1/λmn` 加权，对应速度动能尺度；
- 磁势系数以 `λmn` 加权，对应磁扰动能尺度；
- 温度系数直接以平方和表示热扰动方差。

控制器取三者最大占比，并利用三个占比对数的离散程度调节同一组指数过滤强度。统一过滤传递函数施加到三个物理场，可避免某一场单独强过滤后造成耦合相位/截断层级不一致。触发阈值、阶数、增益和最大强度均可配置，输出 CSV 记录每次控制量。

这是本软件重点设计的算法特征，但其法律上的新颖性与创造性必须通过现有技术检索和专利审查确定。

## 7. 输入输出设计

输入 JSON 分为 `domain`、`physics`、`numerical`、`initial`、`output` 五组。程序启动时进行边界、扩散系数、模态数、时间步和过滤参数校验。

末态 NPZ 同时包含原始模态系数和以下重构数组：坐标、流函数、涡量、速度分量、磁势、磁场分量、电流密度、温度扰动与总温度。CSV 记录动能、磁扰动能、温度方差、涡量平方积分、电流密度平方积分、对流热流、估计 Nusselt 数、场最大值及算法控制指标。

## 8. 验证方案

当前自动测试包括：

1. 任意模态系数经过重构—投影后恢复；
2. `J(f,f)` 在舍入误差范围内为零；
3. 零外力零初值保持静止；
4. 势函数构造的速度/磁场散度相消；
5. 短时耦合算例完成且输出有限。

进入科研或工程应用前建议增加：纯扩散解析衰减、Orszag–Tang 类周期基准的边界适配版本、热对流临界参数、模态收敛曲线、能量预算闭合和实验数据对比。

## 9. 运行环境

- 操作系统：Windows、Linux 或 macOS；
- Python：3.10 及以上；
- 必需依赖：NumPy 1.24 及以上；
- 可选依赖：Matplotlib 3.7 及以上；
- 推荐内存：快速算例 1 GB，高模态算例视模态数和求积网格而定。
