# 飞机翼型流场反馈闭环设计说明

## 1. 功能目标

本模块把“建模—求解—评价—修改—重算”组织成可重复执行的软件闭环：

```text
输入初始翼型与飞行条件
        │
        ▼
生成参数化二维机翼外壳
        │
        ▼
求解外部速度场与表面压力
        │
        ▼
升力/力矩/Cp峰值/厚度/阻力代理评价
        │
   ┌────┴────┐
   │全部通过  │存在未通过指标
   ▼          ▼
输出结果   扰动几何并重算流场敏感度
              │
              ▼
       回溯修改弯度、位置、厚度
              │
              └────────回到流场求解
```

## 2. 外壳模型

外壳采用连续化 NACA 四位数族表达，以三个无量纲变量控制：

- `camber`：最大弯度/弦长；
- `camber_position`：最大弯度位置/弦长；
- `thickness`：最大厚度/弦长。

弦向点使用余弦分布，提高前缘和尾缘附近的面板密度。上表面从尾缘走向前缘，下表面从前缘返回尾缘，形成逆时针闭合轮廓。三个变量都具有显式上下界，优化器不会产生越界外形。

## 3. 流场计算

采用二维 Hess–Smith 势流面板法。每个边界面板设置常强度源分布，整个翼型设置共同环量；控制点满足不可穿透条件，尾缘满足 Kutta 条件。求解线性方程后得到：

- 表面切向速度；
- 表面压力系数 `Cp=1-(Vt/V∞)²`；
- 压力积分升力、压力阻力；
- 四分之一弦长俯仰力矩；
- 翼型外任意网格上的速度和压力系数。

无黏势流不能预测型面黏性阻力。程序另外输出一个明确标记为 `estimated_drag_coefficient` 的概念筛选代理量，由厚度相关型面项、升力相关项和非负压力阻力组成，不能当作真实阻力系数。

## 4. 设计标准评价

每次流场计算后检查：

1. 升力系数是否进入目标容差；
2. 俯仰力矩绝对值是否超限；
3. 最低压力系数是否超过允许的吸力峰值；
4. 厚度是否处于结构预留区间；
5. 阻力代理量是否低于概念设计上限。

这里的“标准”是用户在 JSON 中定义的项目筛选标准，不是适航规章。程序为每个未通过指标生成中文反馈，并把反馈、指标和几何参数写入设计历史。

## 5. 反馈修改机制

优化变量先映射到 `[0,1]`。在当前外形附近分别正负扰动弯度、弯度位置和厚度，每个扰动都重新生成外壳并重新计算流场。由实际目标函数差值得到流场敏感度：

```text
∂J/∂zi ≈ [J(zi+h)-J(zi-h)] / (2h)
```

目标函数包含升力误差和各项超限惩罚，并带有轻微几何正则项。优化器沿归一化负梯度方向提出新外形，通过回溯线搜索确认目标下降。如果约束附近的非光滑性导致梯度方向无效，再对六个坐标方向执行模式搜索。没有更优外形时缩小设计步长。

停止条件为：全部配置标准通过、达到最大迭代次数，或者设计步长小于下限。程序不会把“达到最大迭代次数”错误报告成设计合格。

## 6. 输出文件

- `design_history.csv`：每轮接受状态、气动指标、反馈和修改量；
- `iterations/surface_*.csv`：每轮表面速度和压力；
- `final_geometry.csv`：最终翼型坐标；
- `final_surface_pressure.csv`：最终表面压力；
- `final_aero_field.npz`：最终二维速度场和压力场；
- `design_report.json`：通过状态、停止原因和适用限制；
- `aero_design_summary.png`：可选的流场、压力和收敛图。

## 7. 使用方法

```powershell
omt-aero run examples\aero_auto_design.json
```

示例初始弯度为 `0.006`、厚度为 `0.12`，攻角为 3 度，目标升力系数为 `0.75±0.025`。不同面板数、目标和边界可能得到不同结果。

## 8. 工程适用边界

该模块适合二维亚声速概念筛选、程序闭环演示和进一步连接高保真求解器，不应直接用于飞机定型。真实飞机设计至少还需要：

- 三维机翼、机身、尾翼和推进系统几何；
- 雷诺数、黏性边界层、转捩和分离；
- 可压缩性、跨声速激波和高攻角失速；
- 结构强度、气动弹性、颤振和重量重心；
- 多工况优化、制造约束、风洞试验和适航符合性验证。

模块的接口把几何生成、气动求解、评价器和优化器分开，后续可以用外部 RANS/LES 或网格求解器替换 `HessSmithSolver`，而保留评价与反馈循环。
