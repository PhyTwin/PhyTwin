
## 模块

| 路径 | 功能 |
|---|---|
| `/calculator.html` | 科学计算器 |
| `/plot3d.html` | 3D 函数绘图 |
| `/model.html` | 图纸转交互模型 |
| `/stability.html` | 力学稳定性 |
| `/thermal.html` | 热场 |
| `/wind.html` | 迎面风场（微风 1–3 级） |
