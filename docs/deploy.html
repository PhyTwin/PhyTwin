Deploy

费用与挂域

结论：挂上 phytwin.com 不需要额外花钱（域名年费你本来就在阿里云付）。

要不要钱？

项目费用
域名 phytwin.com你已购买；每年续费照旧
网站托管（Cloudflare Pages）¥0
DNS 解析（阿里云 DNS 指到 Pages）¥0
本机计算 API¥0（电费）
Cloudflare Tunnel 对外暴露本机¥0

不会因为「把域名链上去」就产生一笔新账单。除非你以后买云主机 / CDN 流量超免 / 企业邮箱等增值服务。

1. 本地先预览

  1. 在项目根目录运行：python -m http.server 5500
  2. 浏览器打开 http://127.0.0.1:5500
  3. 另开终端：python local-api/server.py，再打开「试算」页提交

2. 免费部署到 Cloudflare Pages

  1. 把本仓库推到 GitHub / GitLab（或用 Wrangler 直接上传）
  2. 登录 Cloudflare → Workers & Pages → Create → Pages
  3. 连接仓库，构建命令留空，输出目录填 /（静态站根目录）
  4. 部署后会得到类似 https://phytwin.pages.dev

3. 阿里云域名挂到 Pages（免费）

  1. Cloudflare Pages → Custom domains → 添加 phytwin.com 与 www.phytwin.com
  2. 按提示去阿里云 DNS加记录（常见两种）：
    • www → CNAME → xxx.pages.dev（Cloudflare 给你的目标）
    • 根域名 @：若阿里云支持「显性 URL / ALIAS / 阿里云云解析 CNAME 展平」按提示加；或把 DNS 托管转到 Cloudflare（Nameserver 改到 Cloudflare，仍免费）
  3. 等解析生效（几分钟到几小时），HTTPS 证书由 Cloudflare 自动签

注意：改 Nameserver 不等于卖掉域名，域名仍在阿里云；只是解析服务改到 Cloudflare。

4. 让外网调用你的本地电脑

  1. 本机保持运行：python local-api/server.py
  2. 安装并登录 cloudflared，执行例如：
    cloudflared tunnel --url http://127.0.0.1:8787
  3. 会得到一个临时 *.trycloudflare.com 地址；正式环境建议创建命名 Tunnel，绑到 api.phytwin.com
  4. 在试算页把「API 地址」改成该域名，并设置环境变量 PHYTWIN_API_KEY 换掉默认密钥

5. 安全底线

  • 务必改默认 API Key
  • 只暴露计算 API，不要暴露整台电脑桌面
  • 加简单限流；长任务改成异步队列
